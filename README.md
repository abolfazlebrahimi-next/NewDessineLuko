# 🌳 شهر لوکو — بازی شهرسازی و مزرعه‌داری

یک بازی دوبعدی افقی (۲.۵بعدی) شبیه **کلش آف کلنز** با **Three.js** — دو صحنه‌ی جدا (شهر و مزرعه) با انتقال ابری، جنگل انبوه دور هر دو، آدمک‌های کوچکِ پرحرف، حیوانات مزرعه و سیستم ساخت‌وساز (حصار، دیوار، چادر، خانه).

## 🚀 اجرا

```bash
npm install
npm run dev
```

سپس مرورگر را روی `http://localhost:5173` باز کنید.

برای بیلد نهایی: `npm run build` و سپس `npm run preview`.
برای تست‌ها: `npm test`

## 🎮 گیم‌پلی

### ☁️ دو صحنه: شهر و مزرعه
- بازی در **شهر** شروع می‌شود؛ مزرعه داخل صفحه‌ی شهر نیست.
- روی ساختمان **«مزرعه»** کلیک کن (یا دکمه‌ی سبز کنار صفحه) → **ابرها می‌آیند** و وارد فضای جدا و مخصوص مزرعه می‌شوی.
- برای برگشت: دکمه‌ی «برگشت به شهر» یا کلیک روی **خانه‌ی مزرعه**.
- دور هر دو صحنه و بینشان **جنگل انبوهِ** درخت‌های پشت‌به‌پشت است.

### ساختمان‌های شهر
| ساختمان | کلیک روی آن |
|---|---|
| 🎪 **تالار بازی** | جایزه‌ی روزانه (سکه + تجربه) |
| 🏥 **بیمارستان دکتر نیلا** | دریافت کمک (شبنم هدیه) |
| 🏋️ **باشگاه لوکو** | تمرین و گرفتن تجربه |
| 🔧 **مکانیکی** | کار روزانه و دریافت سکه |
| 🌾 **مزرعه** | انتقال ابری به صحنه‌ی مزرعه |

### 🌲 زمین مزرعه و جنگل
- زمین کشت در صحنه‌ی مزرعه **۷۰ سلول** (۱۰×۷) دارد و جایگاه‌ها **کامل به هم می‌چسبند**.
- اول بازی بیشتر زمین زیر **جنگل انبوه درخت و سنگ** است (دور شهر و مزرعه هم همین‌طور).
- روی هر درخت/سنگ **کلیک کن** → هزینه نشان داده می‌شود؛ **دوباره کلیک کن** → با سکه پاک می‌شود و زمین باز می‌شود (+ شبنم و تجربه).

### 🧱 ساخت‌وساز و دیوارکشی
از فروشگاه، زبانه‌ی **«ساخت‌وساز»** این‌ها را بخر و کارت‌شان را روی زمین بینداز:
- 🚧 **حصار چوبی** و 🧱 **دیوار** — روی شبکه‌ی ریز کامل به هم می‌چسبند؛ جهت‌شان خودکار با همسایه تنظیم می‌شود. **کلیک = چرخش ۹۰°**، **دوبار کلیک سریع = برداشتن** (کارت برمی‌گردد).
- ⛺ **چادر** (۲×۲) و 🏠 **خانه‌ی چوبی** (۳×۳) برای تزیین و ساختن محله‌ی خودت — در هر دو صحنه می‌شود ساخت، ولی نه روی زمین کشت و داخل آغل.

### 🐄 حیوانات مزرعه
در آغل شرق زمین **گاو، گوسفند، خوک و مرغ** می‌چرند و قدم می‌زنند. اگر مدل‌های `cow.glb` و… را در `public/models/animals` بگذاری، بازی از آن‌ها استفاده می‌کند؛ وگرنه حیوان مکعبی با کد ساخته می‌شود.

### 🥕 چرخه‌ی کشاورزی
1. کارت **خاک** را ۳ بار روی جایگاه خالی بیندازید → خاک شخم‌خورده.
2. کارت **دانه** (هویج 🥕 / گندم 🌾 / کلم 🥬 / بادمجان 🍆) را بیندازید.
3. مرتب **آب** 💧 و **کود** بدهید.

### 🛒 مشتری‌های واقعی (از آدمک‌ها)
وقتی محصولی رسید، یک مشتری وارد مزرعه می‌شود، محصول را وارسی می‌کند 🤔، شاید اولی را نپسندد و دومی را بخرد 💰، تشکر می‌کند و می‌رود. با کلیک روی جایگاه «آماده فروش» هم فوری فروخته می‌شود.

### 🧍 آدمک‌ها
- **کوچک** هستند (حدود یک‌سوم کوچک‌ترین خانه)، در هر دو صحنه پرسه می‌زنند، گاهی داخل ساختمان‌ها می‌روند و هرازگاهی **دونفره کنار هم گپ می‌زنند** 💬.
- مدل اختیاری: فایل‌های `character-a.glb` تا `character-h.glb` در `public/models/characters`.

### 📊 رابط کاربری
- فونت فارسی **وزیرمتن**، زوم متعادل و قابل مدیریت (غلتک موس)، درگ‌اندراپ کارت‌ها و جابجایی ساختمان‌ها/جایگاه‌ها.
- ذخیره‌ی خودکار در مرورگر؛ ذخیره‌های قدیمی خودکار مهاجرت می‌کنند (تعداد زمین‌های بازشده حفظ می‌شود).

## 🗂 ساختار پروژه

```
index.html            صفحه‌ی اصلی
styles.css            استایل‌ها + فونت وزیرمتن + ابرهای انتقال
src/
  config.js           صحنه‌ها، قیمت‌ها، چیدمان، سازه‌ها، حیوانات، دیالوگ‌ها
  state.js            وضعیت بازی، ذخیره‌سازی نسخه ۳ و مهاجرت
  world.js            موتور Three.js (زمین دو صحنه، دوربین، نور)
  decor.js            جنگل انبوه (InstancedMesh)، چمن، دکور پکیج و حصار آغل
  obstacles.js        درخت‌ها و سنگ‌های قابل پاک‌کردن با سکه (خوشه‌ای)
  constructions.js    ساخت‌وساز: حصار/دیوار/چادر/خانه روی شبکه
  animals.js          حیوانات آغل (مدل GLB یا مکعبی)
  characters.js       آدمک‌ها: پرسه‌زنی، گپ دونفره و مشتری‌ها
  farm.js             جایگاه‌های کشت، رشد و فروش
  ui.js               HUD، فروشگاه، حباب‌ها و انتقال ابری
  audio.js            صداهای بازی (WebAudio)
  main.js             اتصال بخش‌ها + جابجایی صحنه + حلقه‌ی بازی
public/
  assets/             تصاویر بهینه‌شده‌ی بازی
  fonts/              فونت وزیرمتن (woff2)
  models/nature/      درخت/سنگ/چمن (Kenney Survival Kit — CC0)
  models/build/       حصار/دیوار/خانه/چادر و وسایل (همان پکیج)
  models/characters/  (اختیاری) مدل آدمک character-*.glb
  models/animals/     (اختیاری) مدل حیوان cow.glb و...
tests/                تست‌های منطق، ساخت‌وساز و حیوانات، رابط و بوت
assets-src/           فایل‌های منبع و بقیه‌ی پکیج‌ها (آرشیو)
```
