# 🌳 شهر لوکو — بازی شهرسازی و مزرعه‌داری

یک بازی دوبعدی افقی (۲.۵بعدی) شبیه **کلش آف کلنز** با **Three.js** — شهر لوکو با ساختمان‌های ثابت، مزرعه‌ی کشت، درخت‌های قابل ترکاندن و فروشگاه.

## 🚀 اجرا

```bash
npm install
npm run dev
```

سپس مرورگر را روی `http://localhost:5173` باز کنید.

برای بیلد نهایی: `npm run build` و سپس `npm run preview`.

## 🎮 گیم‌پلی

### ساختمان‌های شهر (از اول در بازی هستند)
| ساختمان | کلیک روی آن |
|---|---|
| 🎪 **تالار بازی** (مهم‌ترین) | جایزه‌ی روزانه (سکه + تجربه) |
| 🏥 **بیمارستان دکتر نیلا** | دریافت کمک (شبنم هدیه) |
| 🏋️ **باشگاه لوکو** | تمرین و گرفتن تجربه |
| 🔧 **مکانیکی** | کار روزانه و دریافت سکه |
| 🌾 **مزرعه** | رفتن به مزرعه و مدیریت جایگاه‌های کشت |

### 🌳 درخت‌ها
- چند درخت (Tree1 تا Tree3) از اول کناره‌های مزرعه هستند.
- **نگه‌داشتن ۵ ثانیه‌ای** روی درخت → درخت می‌ترکد 💥 و **شبنم** + تجربه می‌دهد.
- هر چند ثانیه یک درخت تازه در شهر می‌روید.

### 🥕 چرخه‌ی کشاورزی
1. کارت **خاک** را ۳ بار روی یک جایگاه خالی (`Product1.png`) بیندازید → خاک شخم‌خورده (`Product2.png`).
2. کارت **دانه** (هویج 🥕 / گندم 🌾 / کلم 🥬 / بادمجان 🍆) را بیندازید.
3. مرتب **آب** 💧 و **کود** بدهید (بدون آب رشد می‌ایستد؛ کود سرعت رشد را دوبرابر می‌کند).
4. مراحل رشد:
   - گندم: `Product3.png` → `Product4.png`
   - بادمجان: `Eggplantcrop.png`
   - هویج: `Carrotcrop.png`
   - کلم: `Cabbageproduct.png`
5. وقتی محصول رسید برچسب **«آماده فروش»** و **مشتری دست به نقد** می‌آید 🤑 → فروش خودکار یا کلیک روی جایگاه → سکه + تجربه.

### 🛒 فروشگاه (صفحه‌ی جداگانه — دقیقاً به سبک کلش آف کلنز)
- زبانه‌های عمودی: **جایگاه کشت** | **آب و کود** | **دانه‌ها**
- خرید با تعداد دلخواه (×۱ / ×۵ / ×۱۰) — هر چه بخری **همان لحظه به کارت‌های پایین صفحه اضافه می‌شود**
- **جایگاه کشت** (گران — برای توسعه‌ی مزرعه)
- **آب** / **آب‌پاش کامل** (با شبنم — همه‌ی جایگاه‌ها را یک‌جا آبیاری می‌کند)
- **کود**
- **دانه‌های مختلف** (هویج، گندم، کلم، بادمجان)

کارت‌ها در **سینی پایین صفحه** هستند؛ آن‌ها را روی جایگاه‌های مزرعه بکشید و رها کنید (درگ‌اندراپ) با **سایه/هایلایت سبز یا قرمز** برای نشان دادن جای مجاز. مثل کلش، جایگاه‌ها روی هم نمی‌افتند.

### 🧍 آدمک‌های شهر
- مدل‌های سه‌بعدی **Kenney Blocky Characters** (GLB) با انیمیشن راه رفتن و ایستادن
- بین شهر پرسه می‌زنند، گاهی **وارد ساختمان‌ها می‌شوند** و بعد بیرون می‌آیند!

### ✋ جابجایی همه‌چیز با درگ‌اندراپ
- **ساختمان‌ها، درخت‌ها و جایگاه‌های کشت** را بکش و در جای مناسب رها کن
- سایه‌ی جانمایی سبز (مجاز) یا قرمز (غیرمجاز) + جلوگیری از هم‌پوشانی مثل کلش

### 🌳 بازخورد درخت‌ها
- با هاور/لمس، درخت **می‌لرزد و کمی بزرگ می‌شود** + تکان طبیعی دائمی
- **نگه‌داشتن ۵ ثانیه‌ای** → ترکیدن 💥 → شبنم + تجربه

### 🛒 فروش و مزرعه
- وقتی محصول رسید، **مشتری دست به نقد** می‌آید؛ با فروش **کل جایگاه فروخته و از مزرعه پاک می‌شود** 🌾

### 📊 رابط کاربری
- **بالا چپ**: لول کاربر + نوار پیشرفت تجربه تا لول بعدی
- **بالا راست**: تنظیمات ⚙️، سکه 🪙 و شبنم 💧 (زیر هم)
- **پایین راست/چپ**: فروشگاه 🏪، پیام‌ها ✉️ (با نشان قرمز)، دوستان 👥
- **پایین**: سینی کارت‌ها با اسکرول افقی
- ذخیره‌ی خودکار پیشرفت در مرورگر (localStorage)

## 🗂 ساختار پروژه

```
index.html          صفحه‌ی اصلی
styles.css          استایل‌های رابط کاربری (راست‌به‌چپ)
src/
  config.js         قیمت‌ها، محصولات، چیدمان شهر
  state.js          وضعیت بازی + ذخیره‌سازی
  world.js          موتور Three.js (زمین، اسپریت‌ها، افکت‌ها)
  farm.js           منطق جایگاه‌های کشت، رشد و فروش
  trees.js          درخت‌ها: هاور، نگه‌داشتن ۵ ثانیه‌ای و رشد تصادفی
  characters.js     آدمک‌های شهر (مدل‌های Kenney GLB)
  ui.js             HUD، فروشگاه کلش‌مانند، پیام‌ها، دوستان، تنظیمات
  audio.js          صداهای بازی (WebAudio — ضدخطا)
  main.js           اتصال بخش‌ها + درگ‌اندراپ + حلقه‌ی بازی
public/
  assets/           تصاویر بهینه‌شده‌ی وب
  Models/GLB format/ مدل‌های آدمک (Kenney — CC0)
*.png (ریشه)        تصاویر اصلی (منبع)
```
