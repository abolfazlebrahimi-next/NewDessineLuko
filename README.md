# 🏙️ شهر لوکو (Luko City)

بازی شهرسازی سه‌بعدی تحت وب با Three.js — یک شهر کامل با هسته‌ی اصلی، محله‌های مسکونی، حاشیه‌ی صنعتی، خیابان‌ها، ماشین‌های در حال تردد و آدمک‌هایی که در شهر زندگی می‌کنند.

## هسته‌ی شهر (۸ بخش اصلی)

1. **تالار اصلی شهر** — جایزه‌ی روزانه
2. **مطب دکتر نیلا** — دریافت شبنم
3. **ساختمان شورای شهر لوکو** — بودجه‌ی شهر
4. **سینما** — تماشای فیلم و تجربه
5. **کلاب ورزشی** — تمرین و لول‌آپ
6. **باغچه** — فواره، پرچین و گل‌کاری (سه‌بعدی)
7. **لیدربرد** — جایزه‌ی رتبه (از دکمه‌ی «لیدربرد» در HUD باز می‌شود؛ تابلوی روی نقشه حذف شد و جایش پارک کوچک شهر است)
8. **خونه یوزر** — خانه‌ی بازیکن

ساختمان‌های اصلی عکس‌های ایزومتریک‌اند که با توجه به زاویه‌ی دوربین طوری روی زمین نشانده می‌شوند که وسط کفشان وسط بلوک باشد و سایه‌ی تماس زیر کف بیفتد.

## بقیه‌ی شهر

- **پشت هسته (شمال) — مرکز شهر و خط آسمان:** دو ردیف مغازه/آپارتمان Kenney City Kit (Commercial) رو به خیابان در هر بلوک با پهنای واقعی مدل‌ها کنار هم، چتر کافه روی پیاده‌رو؛ ردیف پشتی شهر برج و آسمان‌خراش می‌گیرد تا از دید دوربین خط آسمان بسازد بی‌آنکه جلوی هسته را بگیرد.
- **جلوی هسته (جنوب) و دو طرف — محله‌های مسکونی:** هر بلوک ۴ قطعه با خانه‌های Kenney City Kit (Suburban) رو به خیابان، ماشین‌رو، مسیر پیاده، نرده‌ی چوبی، گلدان، درخت حیاط و گاهی ماشین پارک‌شده در ماشین‌رو.
- **لبه‌های شرقی/غربی — حاشیه‌ی صنعتی:** کارخانه‌ها و انبارهای Kenney City Kit (Industrial)، برج آب، کانتینر، مخزن، دودکش و پنل خورشیدی روی بام.
- **خیابان‌ها:** ۲۱ مدل Kenney Car Kit (تاکسی، پلیس، آمبولانس، آتش‌نشانی، کارت…) با چرخ‌های چرخان در چهار حلقه می‌چرخند؛ ماشین موضوعی جلوی هر ساختمان اصلی پارک است.
- **فضای سبز:** درخت‌های سبز و پاییزی، سنگ و علف از پکیج Kenney Survival Kit (همان پکیج محصول قبلی) در کنار خیابان‌ها، حیاط‌ها، پارک‌ها و دور شهر.

همه‌ی مدل‌های تکراری با `InstancedMesh` رندر می‌شوند (هر مدل یک draw call) و فایل‌های GLB با Meshopt فشرده شده‌اند (حدود ۶ برابر کوچک‌تر) تا شهر سریع لود شود.

## اجرا

```bash
npm install
npm run dev        # سرور توسعه
npm run build      # بیلد production در dist
npm run build:single   # ساخت Luko-Game.html — کل بازی در یک فایل HTML
npm test           # تست‌ها
node scripts/optimize-models.mjs [public/models/...]   # فشرده‌سازی مدل‌های GLB تازه اضافه‌شده (Meshopt)
node scripts/preview-render.mjs                          # پیش‌نمایش CPU شهر بدون مرورگر → /tmp/preview.png
```

### افزودن پکیج مدل جدید

فایل‌های `GLB format` پکیج را در `public/models/<نام>/` بگذار (با پوشه‌ی `Textures/colormap.png` کنارشان) و `node scripts/optimize-models.mjs public/models/<نام>` را اجرا کن؛ بافت داخل فایل‌ها می‌رود و هندسه فشرده می‌شود.

`Luko-Game.html` را می‌شود با دوبار کلیک در مرورگر باز کرد و برای بقیه فرستاد؛ نیازی به سرور ندارد.

## ساختار

- `src/city.js` — ساخت شهر: خیابان‌ها، ساختمان‌های اصلی، مدل‌های سه‌بعدی، ماشین‌ها و آدمک‌ها
- `src/world.js` — رندر و دوربین (Three.js)
- `src/ui.js` — رابط کاربری به سبک بازی‌های موبایل (HUD، پنل‌های تمام‌صفحه، پیام‌ها)
- `src/config.js` — داده‌های شهر و ساختمان‌ها
- `src/state.js` — ذخیره‌ی بازی و اقتصاد (سکه/شبنم محدود)
- `src/loader.js` — لودر GLB مشترک با دیکودر Meshopt و نقشه‌ی دارایی بیلد تک‌فایل
- `public/models/city` (Industrial)، `public/models/commercial` (Commercial)، `public/models/suburban` (Suburban)، `public/models/cars` (Car Kit)، `public/models/nature` (Survival Kit) — مدل‌های Kenney (لایسنس CC0، فایل `Kenney-License.txt`)
- `public/assets/city-*.webp` — تصاویر ساختمان‌های اصلی (اصل PNG در `assets-src/images`)
- `assets-src/nature-pack-original` — پکیج اصلی Survival Kit (OBJ/FBX)؛ GLB درخت‌ها از همین ساخته شده
