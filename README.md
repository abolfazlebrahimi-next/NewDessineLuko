# 🌳 شهر لوکو — بازی شهرسازی و مزرعه‌داری

یک بازی دوبعدی افقی (۲.۵بعدی) شبیه **کلش آف کلنز** با **Three.js** — شهر لوکو با ساختمان‌های ثابت، نقشه‌ی بزرگ، زمین کشتی که اول پر از درخت و سنگ است، آدمک‌های کوچکِ پرحرف و مشتری‌های واقعی.

## 🚀 اجرا

```bash
npm install
npm run dev
```

سپس مرورگر را روی `http://localhost:5173` باز کنید.

برای بیلد نهایی: `npm run build` و سپس `npm run preview`.
برای تست‌ها: `npm test`

## 🎮 گیم‌پلی

### ساختمان‌های شهر (از اول در بازی هستند)
| ساختمان | کلیک روی آن |
|---|---|
| 🎪 **تالار بازی** (مهم‌ترین) | جایزه‌ی روزانه (سکه + تجربه) |
| 🏥 **بیمارستان دکتر نیلا** | دریافت کمک (شبنم هدیه) |
| 🏋️ **باشگاه لوکو** | تمرین و گرفتن تجربه |
| 🔧 **مکانیکی** | کار روزانه و دریافت سکه |
| 🌾 **مزرعه** | رفتن به مزرعه و مدیریت جایگاه‌های کشت |

### 🗺️ نقشه‌ی بزرگ و زمین‌های بسته
- نقشه خیلی بزرگ‌تر از قبل است: با کشیدن صفحه دوربین را جابجا کن و با غلتک موس زوم کن تا همه‌چیز را ببینی.
- زمین کشت جنوب شهر **۴۰ سلول** (۸×۵) دارد، ولی اول بازی بیشترشان با **درخت و سنگ** بسته‌اند؛ فقط چند سلول وسط باز است.
- دور شهر هم درخت و سنگ‌های وحشی ریخته و هرازگاهی یکی تازه می‌روید.

### 🪓 پاک‌کردن درخت و سنگ با سکه
- روی هر درخت/سنگ **کلیک کن** → هزینه‌ی پاک‌کردن بالای آن نشان داده می‌شود.
- **دوباره کلیک کن** → سکه پرداخت می‌شود، مانع می‌ترکد 💥 و زمین برای همیشه باز می‌شود (+ کمی شبنم و تجربه).
- هرچه زمین از بخش باز دورتر باشد، پاک‌کردنش گران‌تر است — پس کم‌کم مزرعه را گسترش بده.
- مدل‌های سه‌بعدی درخت/سنگ از پکیج **Kenney Survival Kit** در `public/models/nature` هستند.

### 🥕 چرخه‌ی کشاورزی
1. کارت **خاک** را ۳ بار روی یک جایگاه خالی (`Product1.png`) بیندازید → خاک شخم‌خورده (`Product2.png`).
2. کارت **دانه** (هویج 🥕 / گندم 🌾 / کلم 🥬 / بادمجان 🍆) را بیندازید.
3. مرتب **آب** 💧 و **کود** بدهید (بدون آب رشد می‌ایستد؛ کود سرعت رشد را دوبرابر می‌کند).
4. مراحل رشد:
   - گندم: `Product3.png` → `Product4.png`
   - بادمجان: `Eggplantcrop.png`
   - هویج: `Carrotcrop.png`
   - کلم: `Cabbageproduct.png`

### 🛒 مشتری‌های واقعی (از آدمک‌های شهر)
- وقتی محصولی رسید، یک **مشتری** از دروازه‌ی شهر وارد می‌شود و می‌آید جلو جایگاه می‌ایستد.
- محصول را **وارسی می‌کند** 🤔 و با حباب حرف نظرش را می‌گوید:
  - شاید محصول اولی را **نپسندد** («نه، این یکی رو نمی‌خوام 🙄») و برود سراغ بعدی؛
  - هرکدام را که پسندید **می‌خرد** 💰 (کل جایگاه فروخته و پاک می‌شود)، تشکر می‌کند و از شهر می‌رود.
- اگر خودت روی جایگاه «آماده فروش» کلیک کنی، همان لحظه فروخته می‌شود.

### 🧍 آدمک‌های شهر
- آدمک‌ها **کوچک** هستند (قدشان حدود یک‌سومِ کوچک‌ترین خانه است).
- در شهر پرسه می‌زنند، گاهی **وارد ساختمان‌ها می‌شوند** و بعد بیرون می‌آیند.
- هرازگاهی **دو نفر کنار هم می‌ایستند و با حباب حرف گپ می‌زنند** 💬.
- اگر فایل‌های `character-a.glb` تا `character-h.glb` را داخل `public/models/characters` بگذاری، بازی خودکار از آن مدل‌ها استفاده می‌کند (قدشان خودکار کوچک تنظیم می‌شود)؛ وگرنه آدمک‌های مکعبیِ ساخته‌شده با کد می‌آیند.

### 🛒 فروشگاه (صفحه‌ی جداگانه — به سبک کلش آف کلنز)
- زبانه‌های عمودی: **جایگاه کشت** | **آب و کود** | **دانه‌ها**
- خرید با تعداد دلخواه (×۱ / ×۵ / ×۱۰) — هرچه بخری همان لحظه به کارت‌های پایین صفحه اضافه می‌شود.

کارت‌ها در **سینی پایین صفحه** هستند؛ آن‌ها را روی جایگاه‌ها بکشید و رها کنید (درگ‌اندراپ) با سایه‌ی سبز/قرمز برای جای مجاز. اگر کارت جایگاه را روی زمینِ بسته (درخت/سنگ) بیندازی، بازی می‌گوید اول باید آن را با سکه پاک کنی.

### ✋ جابجایی با درگ‌اندراپ
- **ساختمان‌ها و جایگاه‌های کشت** را بکش و در جای مناسب رها کن (سبز = مجاز، قرمز = غیرمجاز، بدون هم‌پوشانی).

### 📊 رابط کاربری
- فونت فارسی **وزیرمتن** (فایل‌ها در `public/fonts`)
- **بالا چپ**: لول کاربر + نوار پیشرفت تجربه
- **بالا راست**: تنظیمات ⚙️، سکه 🪙 و شبنم 💧
- **کناری**: فروشگاه 🏪، پیام‌ها ✉️ (با نشان قرمز)، دوستان 👥
- **پایین**: سینی کارت‌ها با اسکرول افقی
- ذخیره‌ی خودکار پیشرفت در مرورگر (localStorage) — ذخیره‌های قدیمی خودکار به نسخه‌ی جدید تبدیل می‌شوند.

## 🗂 ساختار پروژه

```
index.html            صفحه‌ی اصلی
styles.css            استایل‌ها + تعریف فونت وزیرمتن
src/
  config.js           قیمت‌ها، محصولات، چیدمان شهر و نقشه، دیالوگ‌ها
  state.js            وضعیت بازی، ذخیره‌سازی و تولید موانع
  world.js            موتور Three.js (زمین، نور، دوربین، افکت‌ها)
  obstacles.js        درخت‌ها و سنگ‌ها (مدل GLB) + پاک‌کردن با سکه
  characters.js       آدمک‌ها: پرسه‌زنی، گپ دونفره و مشتری‌ها
  farm.js             جایگاه‌های کشت، رشد و فروش
  ui.js               HUD، فروشگاه، پیام‌ها، حباب‌های حرف
  audio.js            صداهای بازی (WebAudio)
  main.js             اتصال بخش‌ها + درگ‌اندراپ + حلقه‌ی بازی
public/
  assets/             تصاویر بهینه‌شده‌ی بازی
  fonts/              فونت وزیرمتن (woff2)
  models/nature/      مدل‌های درخت/سنگ/چمن (Kenney Survival Kit — CC0)
  models/characters/  (اختیاری) مدل آدمک character-*.glb
tests/                تست‌های منطق بازی، رابط کاربری و بوت
assets-src/
  images/             تصاویر اصلی با کیفیت کامل (منبع)
  nature-pack-original/ بقیه‌ی فایل‌های پکیج طبیعت (FBX/OBJ/پیش‌نمایش) برای آرشیو
```
